# Klokin: Release 1 user stories

Format: As a [who], I want [what], so that [why].

## Employee
1. As an employee, I want to be clocked in automatically when I arrive at the shop, so that I never forget to sign in.
2. As an employee, I want a reminder if I haven't signed in by 08:15, so that a missed clock-in gets fixed the same day.
3. As an employee, I want my clock-ins saved even with no data, so that I'm not penalised for having no signal or airtime.
4. As an installer, I want to tap "I'm on site" and pick or add the client, so that site work and travel count as work hours.
5. As an employee, I want to start and end my lunch in the app, with a warning 15 minutes before it ends, so that I don't run over.
6. As an installer, I want to mark my lunch as "cut short" with a reason, so that I'm paid fairly when a job needs me.
7. As an employee, I want to see my month as a heatmap with my total hours, so that I know exactly what I worked.
8. As an employee, I want to send a correction request, so that wrong hours get fixed without an argument.

## Boss
9. As the boss, I want a live feed of who clocked in, when and where, so that I know who's working without phoning around.
10. As the boss, I want to approve or reject correction requests, so that the records stay accurate and trusted.

## Questions to ask at PrintTeq
- How is attendance tracked now, and who adds up the hours at month end?
- How many staff are there, and how many work on site?
- Does everyone have a smartphone with data?
- What's the most annoying part of tracking hours today?
- What time does the day start and end, and how long is lunch?
- How is overtime counted and paid?
- Are staff comfortable with the app using their location while they're clocked in?
- How is leave requested and approved now? Does it belong in Release 1?
- What does the boss need at month end: a payroll export, a printout, or something else?
